# WeatherNow – Weather Forecast Website

WeatherNow is a responsive weather forecast website built using HTML, CSS, and JavaScript. It allows users to search for cities and view real-time weather information along with a 7-day weather forecast.

## Features

- Search weather information by city name.
- Display current temperature.
- Show weather conditions and weather icons.
- Display feels-like temperature.
- Show humidity and wind speed.
- Provide a 7-day weather forecast.
- Loading and error messages.
- Responsive design for desktop and mobile devices.

## Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and responsive layout.
- **JavaScript** – Application logic and API integration.
- **Open-Meteo API** – Weather forecast and geocoding data.

## API Used

WeatherNow uses the free Open-Meteo API:

- [Open-Meteo Weather API](https://open-meteo.com/en/docs)
- [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)

No API key is required.

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Puansangapni/WeatherNow.git
   ```

2. Open the project folder:

   ```bash
   cd WeatherNow
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code.

4. Search for a city to view its weather information.
